3.1 Write a PHP script to create cookie in a form.

<?php
if (isset($_POST['submit'])) {
    $name = $_POST['name'];

    // Create a cookie that expires after 1 hour
    setcookie("username", $name, time() + 3600, "/");

    echo "Cookie created successfully!";
}
?>

<!DOCTYPE html>
<html>
<head>
    <title>Create Cookie</title>
</head>
<body>

<h2>Create Cookie Using Form</h2>

<form method="post">
    Enter Your Name:
    <input type="text" name="name" required>
    <input type="submit" name="submit" value="Create Cookie">
</form>

</body>
</html>
-------------------------------------------------------------------------------------------------------------

Cookie created successfully!
