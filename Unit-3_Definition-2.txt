3.2 Write a PHP script to read the cookie of a form

<?php
if (isset($_COOKIE['username'])) {
    echo "Welcome, " . $_COOKIE['username'];
} else {
    echo "Cookie not found.";
}
?>

<!DOCTYPE html>
<html>
<head>
    <title>Read Cookie</title>
</head>
<body>

<h2>Read Cookie</h2>

<form method="post">
    <input type="submit" name="read" value="Read Cookie">
</form>

</body>
</html>
--------------------------------------------------------------------------------------------------------------
OUTPUT:

Welcome, Walter M Musa
Read Cookie
